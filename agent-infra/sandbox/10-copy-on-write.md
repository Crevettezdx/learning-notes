# CoW 为什么能减少克隆成本

[返回目录](./README.md) · [术语速查](./glossary.md)

> 本页问题：多个实例怎样复用模板，同时保留各自的修改？

**CoW（Copy-on-Write，写时复制）**让实例先共享模板数据，真正写入时再生成自己的副本。

## 一个数据块的变化

```text
模板中的数据块 A
  ├─ 实例 1：先引用 A → 写入时产生私有块 A1
  └─ 实例 2：继续引用 A，不受实例 1 修改影响
```

因此，创建实例时可以避免立即完整复制数 GB 数据；读到的初始内容相同，写入结果彼此独立。

## 文件克隆与内存恢复要区分

- **reflink**：文件系统提供的 CoW 文件克隆能力，常用于克隆系统盘或快照文件。
- **内存 CoW / 按需恢复**：取决于 VMM、内存映射和恢复方式；克隆了一个内存快照文件，不代表 Guest RAM 自动实现零复制或共享。

## 成本何时发生

- 模板数据仍需从存储读取，缓存是否命中会影响速度。
- 私有写入越多，额外内存与磁盘占用越大。
- CoW 减少前期复制，不增加实际 CPU、内存或 I/O 容量。
