# DeepSeek-V4.1-Flash 架构学习笔记

面向 Agent 开发者，围绕“长任务为什么昂贵，新架构如何降低成本，以及能力与可靠性的边界”组织学习。

## 学习目标与完成标准

学完主线后，应能：
- 画出 CED 的输入处理和输出生成路径，说明两者为何成本不同。
- 分清 CSA2 三种模式复用什么，以及分层索引如何减少搜索。
- 解释局部状态为何需要回放、有界回放为何是近似方法。
- 正确解读缓存压缩与计算节省，联系 Agent 工作负载判断收益条件。
- 区分架构效率、训练带来的能力、运行框架带来的表现差异。

不以复现训练、实现推理内核或掌握全部公式为本轮目标。

## 如何逐篇沉淀

每轮只推进一篇：先讲核心问题与机制，用一个 Agent 场景验证理解，再将确认后的内容补入对应文档。跨篇内容使用链接，避免在多个文件中重复解释。

重点篇的最终正文采用：问题 → 必要概念 → 机制或信息路径 → Agent 场景 → 收益与局限 → 自检问题。选读篇只保留概念、作用与边界。

深度约束：
- 重点篇：能讲清完整因果链，必要时保留一张图或一个公式。
- Agent 补充：理解工程含义与使用条件，不进入训练或系统实现。
- 选读篇：知道是什么、解决什么、什么时候再深入即可。
